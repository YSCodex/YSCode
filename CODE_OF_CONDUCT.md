# Code of Conduct

We want this project to be a friendly place for everyone, whatever their background or experience.

**Do:** be respectful, assume good intent, give and accept constructive feedback, and keep discussion about the work.

**Don't:** harass, insult, discriminate, threaten, share other people's private information, or post spam.

Maintainers may edit or remove comments, issues and pull requests that break these rules, and may block repeat offenders.
To report a problem, use the private reporting option on the Security tab of https://github.com/YSCodex/YSCode
and describe it as a conduct report.

This policy applies in all project spaces: issues, pull requests, discussions and any other place where you represent the project.
